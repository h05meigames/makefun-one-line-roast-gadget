One original line roasting a gadget used every day — the microwave that
finishes the job and still demands applause — written for the
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/competitions/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
bounty on [make.fun](https://make.fun/r/0ene8b3q).

## The line

> My microwave beeps when it's done, then beeps again every minute until I open the door — like a toddler who finished its homework and needs applause.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, no trailing newline, 149 characters,
well within the 200-character limit.

## Run it

```sh
node main.ts
```
